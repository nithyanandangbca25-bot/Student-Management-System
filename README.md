# Student Management System

A simple console-based Student Management System developed using Java.

## Features

- Add Student
- View All Students
- Search Student
- Update Student
- Delete Student
- Exit

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner

## Student Information

The system manages:

- Student ID
- Name
- Course
- Semester
- Email

## How It Works

The application provides a menu-driven interface that allows users to add, view, search, update, and delete student records.

Student records are currently stored using Java's `ArrayList`.
